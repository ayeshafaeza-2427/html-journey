  • Difference between tags and elements
  • How browsers read HTML files
  • How to create headings using h1 to h6
  • How to write paragraphs using p tags
  • How to add titles to webpages
  • Importance of head and body tags
  • Basic layout of a webpage

🧠 HTML Structure I Understood

Every HTML document starts with a DOCTYPE declaration. The html tag contains the complete webpage structure. Inside it, the head section stores webpage information, while the body section contains visible webpage content.
