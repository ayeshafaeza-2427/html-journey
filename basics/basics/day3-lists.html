📘 HTML Lists Tutorial

Lists in HTML are used to group related items together. They help organize content in a clean and structured way.

1️⃣ Ordered List

An ordered list displays items in a numbered format. The <ol> tag is used to create ordered lists.

Example:

  1. Wake up
  2. Complete coding practice
  3. Attend classes
  4. Sleep

Here, each item is automatically numbered by the browser.

2️⃣ Unordered List

An unordered list displays items using bullet points. The <ul> tag is used for unordered lists.

Example:

  • HTML
  • CSS
  • JavaScript
  • React

These items are shown with bullets instead of numbers.

3️⃣ Nested Lists

A nested list means placing one list inside another list.

Example:

  • Frontend
    • HTML
    • CSS
    • JavaScript
  • Backend
    • Node.js
    • Python

✅ Summary

HTML provides different types of lists:

  • Ordered Lists → Numbered items
  • Unordered Lists → Bullet point items
  • Nested Lists → Lists inside lists

Lists are very useful for menus, steps, notes, and organizing content on websites.
